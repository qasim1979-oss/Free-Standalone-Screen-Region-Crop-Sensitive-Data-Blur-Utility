# Free Standalone Screen Region Crop & Sensitive Data Blur Utility (.exe)

A fast, lightweight, and 100% offline Windows desktop application designed to capture screen region snippets and brush-blur sensitive information (passwords, bank details, API keys) before sharing.

## 🚀 Key Features
- **Instant Region Snipping:** Select and crop custom screen regions with an interactive overlay.
- **Interactive Brush Blur:** Paint Gaussian blur over confidential text with adjustable brush size and intensity.
- **Undo Functionality:** Easily revert recent blur strokes.
- **Direct Clipboard Integration:** Copy sanitized screenshots directly into your clipboard for immediate pasting.
- **100% Offline & Private:** Process screenshots locally without uploading data to external servers.
